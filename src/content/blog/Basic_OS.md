### 概要
Helloと表示されるだけのOSを作ります。

### 必要な道具を準備する
・NASM：アセンブラという言語を、コンピュータが読める機械語に翻訳するツール。  
  
■ダウンロード/インストール  
NASMの公式サイトのダウンロードページ（ https://www.nasm.us/ ）にアクセスします。  
![画像](/images/03_Basic_OS/1.png)  
Stable と書かれているバージョンのリンクをクリック  
→win64/をクリック  
→「nasm-XXX-installer-x64.exe」をクリック    
→ダウンロードした.exeファイルをダブルクリックしてインストール  

■環境変数（PATH）の設定  
・スタートボタン（Windowsマーク）の横にある検索バーに「環境変数」と入力し、「システム環境変数の編集」を開きます。  
・ウィンドウ右下の 「環境変数」 ボタンをクリックします。  
・「システム環境変数」の欄にある Path を選択し、「編集」 をクリックします。  
・「新規」 をクリックし、先ほどNASMをインストールしたフォルダのパス（例: C:\Program Files\NASM）を入力します。  
・すべてのウィンドウの 「OK」 をクリックして閉じます。  

■動作確認
コマンドプロンプト（またはPowerShell）を新しく開きます。  
以下のコマンドを入力してEnterキーを押します。
```
nasm -v
```

画面に「NASM version XXX compiled on...」のように表示されること確認。  
  
・VMware Workstation Pro  
こちらの準備手順は割愛します。

### コードを書く
テキストエディタを開き、下記のコードを入力し、適当なフォルダで「boot.asm」という名前で保存する。  
```
[org 0x7c00]    ; OSがメモリのどこに読み込まれるかの指定

mov ah, 0x0e    ; BIOSの文字出力機能を使う準備
mov al, 'H'     ; 表示したい文字
int 0x10        ; ビデオサービス（画面出力）を呼び出す
mov al, 'e'
int 0x10
mov al, 'l'
int 0x10
mov al, 'l'
int 0x10
mov al, 'o'
int 0x10

hang:
    jmp hang    ; 無限ループ（プログラムを終了させずに停止させる）

times 510-($-$$) db 0 ; 512バイトぴったりにするために残りを0で埋める
dw 0xaa55             ; これがブートセクタである証（起動時の約束事）
```
  
### OSを動かす
PowerShellを起動し、以下を実行してコンパイルする
```
cd [boot.asmを保存したフォルダ]
nasm.exe -f bin boot.asm -o boot.bin
```

■VMwareで「空の仮想マシン」を作る  
「ファイル」→「新しい仮想マシン」をクリック
![画像](/images/03_Basic_OS/2.png)  
「後でOSをインストール」 を選択。  
ゲストOSの選択では 「その他」 ＞ バージョンも 「その他」 を選択します。  
仮想マシン名は「MyOS」など好きな名前をつけて、ウィザードを進めて完了させます。

■作成したboot.binを読み込ませる。  
作成した仮想マシンの「仮想マシンの設定を編集する」を開く  
フロッピーを選択  
フロッピーイメージファイルを使用するを選択し、  
「参照」から、boot.binを選択する。  
「起動時に接続」にチェックが入っていることを確認し、「OK」で閉じる。  

■起動する  
仮想マシンの「この仮想マシンをパワーオンする」を選択  
「対応するデバイスがホストに存在しないため、～」と出てきたら、「いいえ」を選択。  
  
Helloと表示される  。
